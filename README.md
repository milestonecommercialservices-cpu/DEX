Dex (short for cyberdecks) is a firmware for ESP-32 (and derivatives) interaction with ARM based devices. "Dex" meaning a platform for Codex Gigas, and Holodex UI.

Purpose: To augment non-rooted consumer electronics to provide display, electrical power (battery), connection, and storage. Creating a symbiotic-like
hardware relationship, and central command and control via Holodex UI.

Through the use of tinyML, even small low cost devices based on RISC-V architecture will be able to implement and trigger CODEX GIGAS manifests (python script executions).
